# MiEquipo — Prototipo inicial

Este archivo respalda la sección 8 del informe de Interacción Humano Computador.

## Uso

1. Descargar `index.html`.
2. Abrirlo con un navegador web (Chrome, Edge o Firefox).
3. En **Inicio**, revisar los datos del próximo partido.
4. En **Ver jugadores**, consultar la nómina y seleccionar **Confirmar asistencia**.
5. En **Crear partido**, ingresar fecha, hora, cancha y cupos; guardar para visualizar el detalle.

## Alcance

Prototipo académico de fidelidad media, desarrollado en un único archivo HTML que incluye CSS y JavaScript. Contiene cuatro vistas: Inicio, Crear partido, Jugadores y Detalle. Usa datos ficticios, sin autenticación, servidor, sincronización ni almacenamiento persistente. Al recargar la página se reinician los datos. Las pruebas con usuarios reales están pendientes.

El archivo se presenta en una sola pieza para facilitar su apertura y evaluación; no se requiere instalar software ni dependencias.
